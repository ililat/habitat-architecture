# HABITAT

HABITAT

Описание
Концептуальный сайт архитектурного бюро, посвящённый жилым пространствам и интерьерам. Задача — представить философию проектирования через свет, природные материалы и ощущение спокойствия.

Решение
Тёмная галерейная композиция с чёрно белыми фотографиями, строгим гротеском и моноширинными подписями. При наведении фотографии проектов обретают цвет. Каталог фильтруется по типам пространств, описания проектов вынесены на отдельные страницы. Форма позволяет отправить проектный запрос и сохранить его через бэкенд.

Результат
Адаптивное портфолио из семи страниц с тремя иллюстративными проектами, разделом о подходе и работающим сценарием обращения. Сайт объединяет архитектурную подачу и понятную структуру. Бюро и проекты вымышлены, фотографии Unsplash показывают визуальное направление и не являются авторскими работами бюро.

## Локальный запуск

Требуется Node.js 22 или новее. Внешние зависимости не нужны.

```sh
npm run dev
```

Откройте http://localhost:4173. Для другого порта задайте переменную PORT. Локальные тестовые заявки сохраняются в .local-data и исключены из Git.

## Сборка

```sh
npm run build
```

## Бэкенд

Cloudflare Worker с методом fetch. POST /api/inquiries проверяет данные и сохраняет JSON в R2 через binding BUCKET. GET /api/health возвращает состояние сервиса. Письма не отправляются. Личные данные и заявки не включены в исходники.

GitHub хранит исходники. GitHub Pages не запускает Worker и не заменяет серверный хостинг. Для отдельного развёртывания нужен Cloudflare Worker с R2 binding BUCKET либо совместимая среда.
